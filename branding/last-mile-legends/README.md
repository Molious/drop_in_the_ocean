# Last Mile Legends: Naming

**Last Mile Legends** is the series brand for Night Shift Interactive's three games. Night Shift Interactive stays the studio name.

| Level | Name |
|---|---|
| Studio | Night Shift Interactive |
| Series (main title) | Last Mile Legends |
| Games (subtitles) | Celestial Co-Pilot · Red Alert · Poseidon |

## How a game's name is written
"Last Mile Legends" is always the main title, and the game's own name is the subtitle beneath it.

- Stacked (logos, title cards, key art, store pages): **LAST MILE LEGENDS** large, with the game name smaller underneath.
- On one line (page titles, metadata, captions): `Last Mile Legends — Celestial Co-Pilot`, `Last Mile Legends — Red Alert`, `Last Mile Legends — Poseidon`, joined with an em dash.
